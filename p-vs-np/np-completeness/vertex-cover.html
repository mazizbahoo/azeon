The Vertex Cover Problem

Vertex Cover has already appeared in this series once, back in Post 11. I used it as a supporting example while explaining what a reduction actually is: cities, roads, cameras watching every road, and the fact that an Independent Set and a Vertex Cover are always exact opposites of each other on the same map.

At the time, that was just a warm-up. A clean, gentle example to build intuition for reductions before we got into anything serious. I never actually proved Vertex Cover was NP-Complete. I just used it to demonstrate what a reduction looks like.

Now it's time to do that properly. And here's the thing that surprised me when I actually sat down to write this proof: it is almost free. We already did the hard work. Post 11 gave us the Independent Set / Vertex Cover relationship. Post 15 gave us Clique. This post just needs to connect the two, and the whole proof falls out in a few short steps.

Vertex Cover, Properly Defined​

Quick recap from Post 11, stated formally this time.

Given a graph GGG with vertices and edges, a vertex cover is a set of vertices such that every single edge in the graph has at least one of its two endpoints inside that set. Think of it as placing security cameras on cities, where every road needs a camera watching at least one of its two ends.

The Vertex Cover Decision Problem: given a graph GGG and a number kkk, does GGG have a vertex cover of size kkk or smaller?

Vertex Cover is in NP\mathcal{NP}NP. If someone hands me a set of kkk vertices and claims it's a valid cover, I check every edge in the graph and confirm at least one endpoint is in the set. For a graph with mmm edges, that's O(m)O(m)O(m) work. Polynomial. Easy.

The hard direction, as always, is showing that Vertex Cover is NP-Hard: that everything in NP\mathcal{NP}NP reduces to it. That's what the rest of this post proves, and it proves it through Clique.

The Relationship We Already Have​

Post 11 established this, and I want to restate it cleanly because everything here depends on it.

Take any graph HHH. Take any set of vertices SSS inside it. Here is the fact:

S is an Independent Set in H  ⟺  V(H)∖S is a Vertex Cover of HS \text{ is an Independent Set in } H \iff V(H) \setminus S \text{ is a Vertex Cover of } HS is an Independent Set in H⟺V(H)∖S is a Vertex Cover of H

V(H)∖SV(H) \setminus SV(H)∖S just means "every vertex in HHH that is not in SSS." The symbol ∖\setminus∖ means set difference: take everything, remove what's in SSS.

Why does this hold? If SSS has no edges between any two of its members, then every single edge in the graph must have at least one endpoint outside SSS, because if an edge had both endpoints inside SSS, that would make SSS not independent. "At least one endpoint outside SSS" is exactly the definition of V(H)∖SV(H) \setminus SV(H)∖S being a vertex cover.

So if HHH has nnn vertices total and an independent set of size kkk, then HHH also has a vertex cover of size n−kn - kn−k. Same graph. Opposite groups. One fact, two names.

This Relationship Is Within One Graph

I want to flag this clearly before moving on, because it's about to get confused with something else. The Independent Set / Vertex Cover relationship above happens inside a single graph. SSS and V(H)∖SV(H) \setminus SV(H)∖S live in the same HHH. Nothing about the graph itself changes. Only which vertices we're pointing at changes.

What we're about to add is a second relationship, between Clique and Independent Set, and that one does involve changing the graph. Keeping these two relationships straight is the entire trick to this post.

The Missing Piece: Clique and Independent Set​

Post 15 gave us Clique: a set of vertices where every pair is connected. Independent Set is a set of vertices where no pair is connected. Those definitions are mirror images of each other, and that mirroring becomes exact the moment you flip the graph itself.

Here's the tool we need: the complement graph.

The Complement Graph

Given a graph GGG, its complement G‾\overline{G}G has the exact same set of vertices, but the edges are flipped. Wherever GGG has an edge, G‾\overline{G}G has no edge. Wherever GGG has no edge, G‾\overline{G}G has one.

If uuu and vvv are connected in GGG, they are not connected in G‾\overline{G}G. If they're not connected in GGG, they are connected in G‾\overline{G}G.

Building G‾\overline{G}G from GGG is mechanical: look at every possible pair of vertices, and flip whether an edge exists. For nnn vertices, that's checking (n2)\binom{n}{2}(2n​) pairs, which is O(n2)O(n^2)O(n2). Polynomial. Cheap.

Now the key fact:

G has a Clique of size k  ⟺  G‾ has an Independent Set of size kG \text{ has a Clique of size } k \iff \overline{G} \text{ has an Independent Set of size } kG has a Clique of size k⟺G has an Independent Set of size k

This is almost definitional once you see it. A clique in GGG is a set where every pair is connected in GGG. Flip every edge, and "every pair connected" becomes "every pair not connected." A set where every pair is not connected is exactly an independent set. Same set of vertices, opposite graph, opposite-sounding property, same underlying group.

Chaining Everything Together​

Now watch what happens when we stack the two relationships on top of each other.

G has a Clique of size kG \text{ has a Clique of size } kG has a Clique of size k   ⟺  G‾ has an Independent Set of size k(flip the graph)\iff \overline{G} \text{ has an Independent Set of size } k \quad \text{(flip the graph)}⟺G has an Independent Set of size k(flip the graph)   ⟺  G‾ has a Vertex Cover of size n−k(flip the vertex set, same graph)\iff \overline{G} \text{ has a Vertex Cover of size } n - k \quad \text{(flip the vertex set, same graph)}⟺G has a Vertex Cover of size n−k(flip the vertex set, same graph)

Two flips, chained. One flips the graph (Clique to Independent Set). One flips which vertices we're pointing at (Independent Set to Vertex Cover), and that one doesn't touch the graph at all.

This gives us the entire reduction:

Clique ≤ₚ Vertex Cover

Given any instance (G,k)(G, k)(G,k) of Clique, convert it into the instance (G‾,n−k)(\overline{G}, n - k)(G,n−k) of Vertex Cover, where nnn is the number of vertices in GGG.

GGG has a clique of size kkk if and only if G‾\overline{G}G has a vertex cover of size n−kn - kn−k.

The conversion itself is: build the complement graph (O(n2)O(n^2)O(n2)), and subtract kkk from nnn (one subtraction). Both trivially polynomial. The reduction is valid.

Since Clique is NP-Complete (Post 15) and this reduction runs in polynomial time, and Vertex Cover is in NP\mathcal{NP}NP (shown above), Vertex Cover is NP-Complete.

That's the whole proof. It's short because we weren't starting from zero. We were assembling parts we'd already built.

Walking Through a Concrete Example​

Let's trace this with actual vertices so none of it stays abstract.

Our graph GGG: five vertices, AAA through EEE, with edges:

(A,B),(A,C),(B,C),(C,D),(D,E)(A,B), \quad (A,C), \quad (B,C), \quad (C,D), \quad (D,E)(A,B),(A,C),(B,C),(C,D),(D,E)

  • Step 1 — Find a Clique in G
  • Step 2 — Build the Complement Graph
  • Step 3 — Confirm the Independent Set
  • Step 4 — Read Off the Vertex Cover

Check the set {A,B,C}\{A, B, C\}{A,B,C}. Is every pair connected in GGG?

  • (A,B)(A,B)(A,B): yes, it's in our edge list.
  • (A,C)(A,C)(A,C): yes.
  • (B,C)(B,C)(B,C): yes.

All three pairs connected. {A,B,C}\{A, B, C\}{A,B,C} is a clique of size k=3k = 3k=3 in GGG.

GGG has 5 vertices, so there are (52)=10\binom{5}{2} = 10(25​)=10 possible pairs total. GGG uses 5 of them as edges. The complement G‾\overline{G}G gets the other 5, the pairs that were not edges in GGG:

(A,D),(A,E),(B,D),(B,E),(C,E)(A,D), \quad (A,E), \quad (B,D), \quad (B,E), \quad (C,E)(A,D),(A,E),(B,D),(B,E),(C,E)

Every pair from GGG is now a non-edge in G‾\overline{G}G, and every non-edge from GGG is now an edge in G‾\overline{G}G.

Check {A,B,C}\{A, B, C\}{A,B,C} against G‾\overline{G}G's edge list. For this to be an independent set, none of these pairs should appear as edges in G‾\overline{G}G.

  • (A,B)(A,B)(A,B): not in G‾\overline{G}G's edge list. Good.
  • (A,C)(A,C)(A,C): not in the list. Good.
  • (B,C)(B,C)(B,C): not in the list. Good.

{A,B,C}\{A, B, C\}{A,B,C} has zero edges between its members in G‾\overline{G}G. It's a valid independent set of size 3, exactly as the theory predicted.

V(G‾)∖{A,B,C}={D,E}V(\overline{G}) \setminus \{A,B,C\} = \{D, E\}V(G)∖{A,B,C}={D,E}.

n−k=5−3=2n - k = 5 - 3 = 2n−k=5−3=2. So {D,E}\{D, E\}{D,E} should be a vertex cover of size 2 for G‾\overline{G}G. Check every edge of G‾\overline{G}G:

  • (A,D)(A,D)(A,D): covered by DDD. ✓
  • (A,E)(A,E)(A,E): covered by EEE. ✓
  • (B,D)(B,D)(B,D): covered by DDD. ✓
  • (B,E)(B,E)(B,E): covered by EEE. ✓
  • (C,E)(C,E)(C,E): covered by EEE. ✓

Every single edge of G‾\overline{G}G has at least one endpoint in {D,E}\{D, E\}{D,E}. Valid vertex cover, size 2, exactly n−kn - kn−k.

Start with a clique in GGG, end with a vertex cover in G‾\overline{G}G, and the size relationship n−kn - kn−k held exactly. Nothing about the answer got lost translating through two flips.

Why the Two Flips Don't Cancel Out​

Something worth sitting with, because it tripped me up briefly while writing this.

You might wonder: if we flip the graph once (Clique to Independent Set) and then work within that flipped graph (Independent Set to Vertex Cover), are we accidentally flipping twice and ending up back where we started? No, and the reason is that these are two completely different kinds of "flip."

Flipping the graph means changing which pairs of vertices have edges. Flipping the vertex set means changing which vertices we're pointing at, while the graph underneath stays fixed. The first operation changes GGG into G‾\overline{G}G. The second operation changes SSS into V∖SV \setminus SV∖S, but never touches the graph again once we're working inside G‾\overline{G}G.

Keep the Two Complements Separate

"Complement of a graph" and "complement of a vertex set" sound similar and use the same word, but they're doing completely different jobs here. The graph complement happens once, converting the Clique question into an Independent Set question. The vertex set complement happens after that, converting the Independent Set question into a Vertex Cover question, without touching the graph again. Mixing these up is the single easiest way to get lost in this proof.

What We Have Built​

Vertex Cover is NP-Complete. It's in NP\mathcal{NP}NP because a proposed cover can be checked in polynomial time: scan every edge, confirm at least one endpoint is in the set. It's NP-Hard because Clique reduces to it: flip the graph to turn a clique question into an independent set question, then flip the vertex set to turn that into a vertex cover question. Two flips, both free, both polynomial.

What We Have Established

Vertex Cover is NP-Complete. Membership in NP\mathcal{NP}NP comes from checking a proposed cover against every edge in polynomial time. NP-Hardness comes from a reduction chain: GGG has a clique of size kkk if and only if G‾\overline{G}G has a vertex cover of size n−kn - kn−k, where G‾\overline{G}G is the complement graph. The conversion, building the complement and subtracting kkk from nnn, runs in polynomial time. This proof leaned entirely on two relationships already built in Post 11 (Independent Set ↔ Vertex Cover) and Post 15 (Clique).
